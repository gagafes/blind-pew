# Andrey Popovich

I build open-source desktop applications for Linux.

## Projects

### [Blind Pew](https://github.com/gagafes/blind-pew)

Offline transliteration for Linux. Seven languages, eight profiles,
QWERTY/QWERTZ and F12 or tray-wheel switching. For Debian and Ubuntu,
with GNOME and Xfce integration.

[Download Blind Pew](https://github.com/gagafes/blind-pew/releases/latest) · [Documentation](https://github.com/gagafes/blind-pew#readme)

### [Malferma Libro](https://github.com/gagafes/malferma-libro)

A desktop ebook reader for Debian and Ubuntu, with a local library,
OPDS catalogs and a multilingual GTK interface.

[Download Malferma Libro](https://github.com/gagafes/malferma-libro/releases/latest) · [Documentation](https://github.com/gagafes/malferma-libro#readme)
